# ADR-003: доверенный шлюз активации коротких кодов

## Статус

Принято к реализации для закрытия фазы 4.

## Контекст

Текущий PostgreSQL RPC ограничивает перебор по аккаунту. Этого недостаточно:
злоумышленник может создавать аккаунты или распределять запросы. Правило WAF на
домене приложения не защищает прямой вызов Supabase RPC, поэтому ограничение
Cloudflare без изменения маршрута можно обойти.

## Решение

- Клиент активирует короткий код только через Supabase Edge Function
  `redeem-quest-code`.
- Edge Function проверяет JWT пользователя и не доверяет переданному клиентом
  `user_id`.
- IP-адрес и идентификатор устройства не сохраняются. Шлюз передаёт в базу только
  необратимый HMAC-отпечаток с отдельной серверной солью.
- База одновременно применяет два окна: существующее строгое ограничение по
  аккаунту и более широкое ограничение по сетевому/устройственному отпечатку.
- Внутренний RPC активации доступен только `service_role`; прямой вызов старых RPC
  ролью `authenticated` запрещается после переключения frontend.
- Ответы для неправильного, истёкшего и отозванного кода остаются нейтральными.
- При недоступности шлюза активация закрывается безопасно и не выполняется напрямую.
- Открытые коды, JWT, исходные IP, точные координаты и персональные данные детей не
  попадают в таблицы попыток и журналы.

## Порядок rollout

1. Добавить таблицу отпечатков, внутренний RPC и pgTAP-тесты окон/изоляции.
2. Добавить Edge Function и тесты обработки JWT, CORS и нейтральных ошибок.
3. Перевести frontend на `supabase.functions.invoke`.
4. Проверить локально account/IP/device limits и идемпотентную успешную активацию.
5. Развернуть функцию и серверную соль на stage.
6. После stage smoke отозвать `execute` старых RPC у `authenticated`.
7. Повторить проверку обхода прямым REST/RPC-запросом перед production.

## Последствия

Появляется дополнительный серверный компонент и секрет для HMAC, но ограничение
становится непреодолимым прямым обращением к базе. Cloudflare WAF можно оставить
дополнительным внешним слоем, но он не является единственным механизмом защиты.
