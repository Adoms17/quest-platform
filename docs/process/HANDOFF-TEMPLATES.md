# Шаблоны передачи

## Поручение

- ID / Issue, статус, исполнитель, дата.
- Цель и измеримые критерии приёмки.
- Репозиторий, абсолютный путь, исходная ветка и полный commit, рабочая ветка codex/….
- Допустимые файлы/область; что менять нельзя.
- Зависимости, ссылки Notion, известные ограничения и ресурсы.
- Команды обязательных проверок и ожидаемый результат.
- Разрешения Алексея: конкретные действия; если отсутствуют — commit/push/merge/deploy запрещены.
- Передать отчёт по шаблону ниже; самостоятельно не сливать и не публиковать.

## Изменения постановки

Дата; исходное требование; согласованное Алексеем изменение; причина; влияние на границы/зависимости/безопасность; актуальные критерии. Указать подтверждение владельца текстом без предположений. Обновить Issue и связанные страницы Notion. Отдельно записать любые разрешения на внешние действия.

## Отчёт Дани

- Задача и итоговый статус (обычно Review).
- Что сделано и соответствие каждому критерию.
- Изменения постановки, согласованные с Алексеем.
- Файлы, страницы Notion, технические решения.
- Команды проверок: рабочая папка, фактический результат, пропуски/ошибки.
- Миграции: где применены, где нет; RLS/offline-проверки.
- Ветка/commit/PR либо точный локальный путь и git diff; git status.
- Риски, ограничения и незавершённое.
- Ресурсы: приложение, порт, конфигурация, база/контейнер, миграции; что оставлено запущенным.
- Что проверить Роме; что требуется от Алексея.

## Приёмка Ромы

Актуальная постановка сверена; diff и документы проверены; необходимые проверки выполнены с результатами; принятые/отклонённые пункты; статус задачи; отдельный статус выпуска. Не обозначать принятие и deployment одним словом «готово».
