# ADMIN-QUEST-STATISTICS-01 — статистика квестов

Алексей подтвердил правила 25.09.2026. Продолжение локальной работы codex/organization-participants; предыдущие изменения профилей сохранены. Публикация отдельно.

## Метрики

- Уникальные участники: различные participant_profile_id в прохождениях, начатых за период. Профиль, а не аккаунт пользователя. Один профиль в разных организациях считается один раз в платформенном итоге.
- Начатые прохождения: отдельные попытки по started_at.
- Все статусы относятся к дате старта прохождения (started_at), независимо от даты завершения. Состояние определяется на момент запроса.
- В процессе: finished_at отсутствует, с последней серверной активности прошло менее 24 часов.
- Зависшие: finished_at отсутствует, прошло 24 часа и более.
- Завершённые досрочно: finished_at заполнен, не все задания окончены (включая остановку участником или таймер).
- Завершённые: finished_at заполнен, total_tasks > 0 и completed_tasks + failed_tasks >= total_tasks. Исчерпанные попытки задания считаются оконченным заданием, это не доля правильных ответов.
- Четыре статуса составляют ровно число начатых прохождений.
- Начатые квесты: разные quest_id с хотя бы одним начатым прохождением за период, не созданные/опубликованные квесты.
- Для всей платформы дополнительно: разные организации с начатыми прохождениями.

Дни и календарные месяцы по Europe/Moscow, недели с понедельника. Обе выбранные даты включены; в SQL полуоткрытый диапазон до следующего дня. Крайние интервалы обрезаются выбранными датами. Пустые интервалы возвращают нули. Уникальные итоги за период считаются отдельно, не суммируются из строк. Максимум 366 интервалов и 3660 дней в запросе.

Источник — сохранившиеся серверные попытки. Удалённые квесты/попытки не восстанавливаются; ещё не синхронизированные offline-прохождения отсутствуют. Поздняя синхронизация может изменить прошлые значения. Это оперативная статистика, не неизменяемый финансовый отчёт. Объединение профилей для тарификации не применяется к этому согласованному подсчёту по profile_id.

## Доступ и интерфейс

Организация: owner/operations с действующим назначением и MFA. Платформа: только назначение на всю платформу, scoped operations глобальные итоги не получает. Отдельное право и аудит; агрегаты без имён и идентификаторов участников/квестов. Пользовательские RLS не меняются.

Режимы: Online, Hybrid, Secure online. По умолчанию выбраны все; один или несколько режимов фильтруют общие итоги, график и интервалы. Пустой выбор запрещён. Уникальные итоги считаются без повторов между режимами. Отдельные строки по каждому выбранному режиму доступны в итогах и внутри каждого интервала. Используется текущий verification_mode квеста; исторический снимок режима на старте отсутствует.

В карточке организации вкладка «Статистика», в верхней навигации админки «Статистика платформы». Даты, выбор дня/недели/месяца, итоговые карточки, график выбранной метрики и таблица. При отказе/смене организации прежние данные очищаются.
