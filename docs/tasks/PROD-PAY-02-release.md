## Сбой и восстановление
Если публикация одной из функций не завершилась, миграция не применяется. Повтор выпуска безопасен: совместимые функции поддерживают прежнюю схему, а уже применённая миграция определяется по истории. При сбое после миграции сохранить совместимый обработчик и выключенную отправку; не откатывать функции к версии, не понимающей тело без receipt. Сохранённые операции не менять и не повторять денежные POST вручную.
