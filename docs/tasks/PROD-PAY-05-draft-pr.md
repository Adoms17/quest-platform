# Draft PR: повторная авторизация sandbox-отправок и сверка production baseline

Цель PR — закрыть два пути повторной отправки сохранённых sandbox-операций после смены среды и сделать воспроизводимой подготовку миграционного пакета. Ветка codex/production-billing-package-plan, база 07b7395a9e6a831ede0f21f6d4519d377a5224d4, целевая ветка staging. Статус: текст локального draft PR; PR ещё не создан.

## Изменение поведения

Фискальный worker before_send теперь проверяет среду до разрешения повторной отправки. Восстановление обычного возврата recover требует sandbox, пока provider_refund_id неизвестен; чтение уже идентифицированного возврата остаётся доступным. Исходные функции проверяются по SHA-256, ACL и сигнатуры сохраняются. Исторические миграции не изменены; guard/pin остаются кандидатами вне автоматического db push.

Добавлены регрессии с сохранёнными операциями: запрет production/unconfigured, отсутствие частичного применения возврата, отсутствие повторного изменения доступа, запрет HTTP POST при отказе/потере ответа SQL. Проверяются конечные ACL девяти серверных gateway и административные сценарии owner/MFA.

## Подготовка baseline

Добавлены локальные инструменты сверки истории/пакета и read-only запросы. Production-снимок 99 версий/SQL сопоставлен с локальными файлами; девять групп каталога совпали после уточнения локальных default privileges. Одноразовый стенд уточнён по API-ролям/schema privileges. Документы отделяют локальные доказательства от hosted-полномочий и удалённой приёмки.
