# Актуальные тарифы публичного сайта

Согласовано Алексеем: цена за месяц хранится в версии тарифа, редактируется в черновике, фиксируется при публикации. Первоначальное заполнение: Free 0 ₽, Pro 990 ₽, Business 2490 ₽. Валюта RUB, период месяц. Тестовые предложения оплаты не являются источником публичных цен.

## Реализовано локально
- Миграция 20260926038000: monthly_price_minor, заполнение существующих версий и черновиков, сохранение/предпросмотр/публикация цены, публичный RPC read_public_tariff_catalog.
- Старые клиенты при отсутствии параметра цены сохраняют цену черновика либо наследуют цену исходной версии.
- Публичный RPC выбирает Free/Pro/Business по серверному времени через current_tariff_version; будущие, отозванные и версии с завершённой поддержкой не выдаются. История и черновики анонимно недоступны.
- Админка: поле цены в рублях с точностью до копейки, просмотр цены версии.
- Сайт в website-payment-readiness.local: PublicTariffs.jsx и tariffCatalog.mjs загружают текущие цены/лимиты при открытии, без кеша и статического fallback. Ошибка/неполный каталог дают повтор загрузки. Условия оплаты ссылаются на каталог вместо дублирования сумм. Слово «проект» убрано из названий ссылок; предупреждения о статусе документов сохранены.
