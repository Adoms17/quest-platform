# План внешних ресурсов карт — без смены провайдера

Проверка исходников PR183 и официальных источников 22.10.2026. Этот документ не меняет карты, сетевые настройки или инфраструктуру.

## Что можно отдавать с origin приложения

`src/components/MapPicker.jsx:9–11` использует три PNG с cdnjs (Leaflet 1.7.1), хотя lockfile уже фиксирует локальный Leaflet 1.9.4. CSS импортируется из npm в MapPicker, QuestOverviewMap, TaskLocationMap и index.css.

Предлагаемое отдельное изменение: импортировать `leaflet/dist/images/marker-icon.png`, `marker-icon-2x.png`, `marker-shadow.png` через Vite в один модуль настройки маркера. Бандлер сформирует локальные hashed URLs. Проверить все карты и default-icon настройки, обычный/retina экран, CSS marker paths, отсутствие cdnjs в build и отсутствие внешнего запроса при открытии редактора. Зафиксировать визуальную совместимость перехода PNG 1.7.1→1.9.4; зависимости обновлять не нужно. Удаление CDN URL пока не выполнено.

Leaflet допускает локальную поставку файлов из `node_modules/leaflet/dist`: https://leafletjs.com/download.html . В установленном `node_modules/leaflet/LICENSE` — BSD-2-Clause: сохранить copyright, условия и disclaimer, для бинарной поставки также воспроизвести их в сопроводительных материалах. Предлагается включить полную лицензию в распространяемый third-party notices файл и проверить его наличие в build. Это касается библиотеки/её ресурсов, не даёт права копировать произвольные картографические tiles.

## Карта требует отдельного решения

MapPicker.jsx:69, QuestOverviewMap.jsx:99, TaskLocationMap.jsx:256 используют `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png` и видимую атрибуцию OSM. Локальные marker PNG устранят только cdnjs, а не tile-запросы. Same-origin proxy также не доказывает отсутствие передачи поставщику: остаются серверные запросы, география и журналы.

Официальная tile policy: https://operations.osmfoundation.org/policies/tiles/ . Для стандартного сервиса указаны точный HTTPS URL без `{s}`, видимая атрибуция, корректный Referer, соблюдение cache headers; bulk download/prefetch запрещены, SLA нет. Нельзя решать офлайн-карты массовым скачиванием с этого endpoint. Изменение Referrer-Policy ради скрытия источника не считать совместимым решением. Перед будущей реализацией повторно проверить применимые условия.

OSM данные распространяются по ODbL: https://www.openstreetmap.org/copyright . Нужны атрибуция и обозначение лицензии; распространение модифицированной базы требует отдельной проверки условий ODbL. Сохранить читаемую атрибуцию на всех размерах экранов и в согласованном офлайн-варианте. Право на данные и условия конкретного tile-хостинга различаются.

Варианты для решения владельца:

1. Оставить стандартные online tiles при совместимых нагрузке/политике и документированных внешних передачах. Это не российская локализация и не гарантированный offline map service.
2. Выбрать контрактного tile-поставщика с проверенными регионами, обработчиками, журналами, SLA, тарифами и правом офлайн-пакетов. Пока ни поставщик, ни цена, ни договор не выбраны.
3. Разместить собственный renderer/tiles из разрешённого источника данных. Нужно оценить региональное покрытие, zoom, размер, обновления, RAM/CPU/storage/traffic, backup и эксплуатацию. Нельзя обещать, что обсуждаемый VPS 4 CPU/8 GB выдержит это без измерений. Никакие ресурсы не созданы.

## Следующие технические шаги после выбора

- Отдельный небольшой diff локальных PNG и notices; локальный тест сетевых обращений и визуальная проверка всех трёх карт.
- Единый контракт map configuration: URL, attribution, zoom, cache/offline policy и fail-closed поведение без скрытого fallback к внешнему хосту. Не включать новый provider автоматически.
- Проверить текущие Service Worker/offline package пути: не добавлять prefetch стандартных OSM tiles. Отдельно определить, что входит в офлайн-квест и что происходит без подложки карты, сохранив полный продуктовый scope и GPS/контент.
- Для выбранного варианта составить data-flow (клиент/IP/tile coordinates/Referer → provider/logs/backups), проверить политику ПДн и эксплуатационный бюджет. География CDN, срок хранения логов и субподрядчики сейчас неизвестны.

Никакие юридические гарантии, новое согласие пользователя на передачу, смена поставщика или ограничения функциональности этим планом не установлены.
